桌面壳带来了什么

不只是把网页装进窗口——围绕 DSH 的进程模型做了完整的桌面工程化。

🚀

零依赖启动

Electron 内嵌 Node 直接运行 DSH 服务（默认 127.0.0.1:3080），终端用户无需安装任何运行时。

🛡️

环境隔离

一切运行在专用 Profile（~/.dsh/profiles/dsh-workbench）内，插件预装与升级不污染你现有的 DSH 环境。

♻️

进程健壮性

健康检查、崩溃指数退避重启、端口冲突自动协商、优雅退出无孤儿进程。

🧩

插件生态

配套 Cordis 插件随应用分发：诊断工具、会话统计与 token 用量面板，持续迭代中。

📦

独立运行时

DSH 全家运行时以真实文件随包分发（asar 之外），模块解析与官方安装行为一致，升级零冲突。

🔧

可诊断

Web 控制台错误透传到应用日志；让 agent 运行 workbench_info 即可采集环境快照。
